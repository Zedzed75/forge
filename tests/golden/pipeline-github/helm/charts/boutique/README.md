# Chart `boutique`

Boutique en ligne, chaine complete

> Chart generated by forge from `forge.yml`, at the root of the repository. To
> regenerate it: `forge generate --only helm`. To receive only the evolutions of
> the template without losing your modifications: `forge update --only helm`.

| | |
|---|---|
| Chart version | `0.1.0` |
| Application version | `1.0.0` |
| Supported Kubernetes | `>=1.34.0-0` |
| Environments | `dev`, `prod` |
| Components | `api` |

## Installation

Each environment is deployed by layering its values file over `values.yaml`. The
order of the `--values` matters: the last one wins.

### dev

```bash
helm upgrade --install boutique ./charts/boutique \
  --namespace boutique-dev --create-namespace \
  --values ./charts/boutique/values.yaml \
  --values ./charts/boutique/values-dev.yaml
```

### prod

```bash
helm upgrade --install boutique ./charts/boutique \
  --namespace boutique-prod --create-namespace \
  --values ./charts/boutique/values.yaml \
  --values ./charts/boutique/values-prod.yaml
```

## Structure of the chart

| File | Role |
|---|---|
| `Chart.yaml` | Metadata: name, versions, Kubernetes compatibility. |
| `values.yaml` | Default values, common to every environment. |
| `values-dev.yaml` | Divergences specific to the `dev` environment (namespace `boutique-dev`). |
| `values-prod.yaml` | Divergences specific to the `prod` environment (namespace `boutique-prod`). |
| `templates/_helpers.tpl` | Naming and labelling helpers, used everywhere. |
| `templates/NOTES.txt` | Message displayed after installation. |
| `templates/deployment-api.yaml` | Deployment of the `api` component. |
| `templates/service-api.yaml` | Service of the `api` component. |
| `templates/tests/test-connection.yaml` | Test run by `helm test`. |

## Values

### Global

| Key | Default | Role |
|---|---|---|
| `global.imageRegistry` | `ghcr.io` | Registry common to every component. |
| `global.imagePullSecrets` | `[]` | Pull secrets for a private registry. |
| `global.environment` | `""` | Name of the environment, set as a label on the resources. |
| `nameOverride` | `""` | Replaces the name of the chart in the composed names. |
| `fullnameOverride` | `""` | Replaces the name of the resources entirely. |
