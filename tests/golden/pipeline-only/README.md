# passerelle

Application gateway, pipeline only

Project generated by **forge** from `forge.yml`. Every structural
change goes through that file: edit it, then run `forge generate`
again, or pick up template changes with `forge update`.

## Identity

- **Service**: `passerelle`
- **Owner**: Platform Team
- **Environments**: prod

## Generated domains

| Domain | Directory | Role |
| --- | --- | --- |
| Pipeline | repository root | Integration pipeline: one job per domain, build, deploy |

Each domain is self-contained: its `.copier-answers.yml` lets it be
updated on its own (`forge update --only <domain>`), and deleting it
does not affect the others.

## Useful commands

```bash
forge generate          # regenerate every domain from forge.yml
forge validate          # each domain's validators + consistency checks
forge diff              # difference between the target and a fresh render
forge update            # apply template changes
```
